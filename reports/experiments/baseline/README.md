# Baseline Run

This directory is populated by `scripts/train.py`, `scripts/evaluate.py`, and
`scripts/infer.py`.

Required files:

- `config.yaml`
- `run.log`
- `progress.json`
- `metrics.json`
- `summary.md`
- `curves.png`

The provisional baseline split must be replaced by the data owner's frozen
`data/splits/main_split.json` before formal comparison experiments.
