# PPT 制作说明

## 一、总体方向

- PPT 的核心是公开 U-Net++，主体篇幅讲清模型原理、实现流程、公开结果和团队在 U-Net++ 上的改进。
- 汇报主线：**医学问题 -> 数据集 -> 公开 U-Net++ -> 团队实验规划 -> U-Net++ 改进 -> 定量结果 -> 结论与分工**。
- 团队实验部分重点讲 U-Net++ 改进。简化 2D U-Net 基线与数据、编码器、损失、分辨率四个探索方向只用一页带过，说明这是团队由简到繁的实验规划思路，不逐项强调探索分支效果。
- PPT 页面不显示内部实验编号，避免产生实验编号连续性问题。
- 汇报聚焦模型原理、实现方案、分割结果和团队改进，不展开与主线无关的指标口径讨论。
- 所有指标注明评估集和来源。

推荐篇幅比例：

| 模块 | 建议占比 | 说明 |
| --- | ---: | --- |
| 项目背景与数据 | 15% | 医学场景、医学意义、数据集组成 |
| U-Net++ 模型 | 40% | 原理、结构、训练与推理流程、公开结果 |
| 团队实验与 U-Net++ 改进 | 25% | 基线及四个方向仅作规划回顾，重点展示 U-Net++ 改进 |
| 结果与结论 | 15% | 定量指标、样例图、优缺点与改进方向 |
| 团队分工 | 5% | 每位成员承担的具体工作 |

## 二、逐页结构

### 第 1 页：封面

- 标题：**基于 U-Net++ 的脑卒中 CT 图像分割**
- 副标题：Brain Stroke CT Dataset 期末项目
- 展示课程名称、团队名称、成员姓名和日期。
- 视觉建议：使用一张脑 CT 或分割结果作为背景，文字区域保持清晰可读。

### 第 2 页：项目背景

- 介绍脑出血和缺血性脑卒中的医学场景，以及病灶定位对观察和辅助分析的意义。
- 说明图像分割任务：输入 CT 图像，输出卒中相关区域的二值掩码。
- 用简洁流程连接“CT 图像 -> 病灶分割 -> 可视化结果”。
- 本页快速建立问题，不展开算法与实验细节。

### 第 3 页：数据集

- 数据集：`Brain Stroke CT Dataset`。
- 总图像数：6,850。
- 分组：Bleeding 1,093、Ischemia 1,130、Normal 4,427、External_Test 200。
- 主数据集用于训练和内部评估，`External_Test` 用于独立外部测试。
- 视觉建议：放 Bleeding、Ischemia、Normal 三类示例，以及一张原始 CT 与分割掩码的对照图。

### 第 4 页：公开 U-Net++ 模型概览

- 本页进入汇报核心，明确项目采用已有公开 U-Net++ 作为主要方案。
- 模型结构：**EfficientNet-B0 预训练编码器 + U-Net++ 解码结构**。
- 训练设置：Dice+BCE 混合损失、数据增强、AdamW、余弦退火、50 个 epoch。
- 公开参考结果：全部图像平均 Dice **0.8354**、IoU **0.8154**。
- 选择理由：预训练编码器提供较强的特征表达能力，U-Net++ 的嵌套跳跃路径适合融合多尺度病灶特征。

### 第 5 页：U-Net++ 模型原理

- 先简要说明基础 U-Net：编码器提取多级特征，解码器恢复分辨率，跳跃连接保留空间细节。
- 再说明 U-Net++：在编码器和解码器之间加入嵌套、密集的跳跃路径，使不同层级的特征逐级融合。
- 核心优势：减小浅层细节与深层语义之间的差距，提高多尺度特征利用率。
- 视觉建议：结构图突出三部分：
  1. EfficientNet-B0 特征提取；
  2. 嵌套跳跃路径；
  3. 上采样与掩码输出。
- 讲稿提示：重点讲“预训练编码器、嵌套连接、多尺度融合”，不需要逐层背诵通道数。

### 第 6 页：U-Net++ 实现流程

- 数据处理：读取 CT 图像和标注，同步裁剪与缩放，归一化，数据增强。
- 训练过程：输入 U-Net++，产生分割 logits，计算损失并反向传播，在验证集上选择最佳权重。
- 推理过程：输出概率图，按固定阈值二值化，得到病灶掩码。
- 评估过程：使用 Dice、IoU、Precision、Recall 等指标评价分割结果。
- 视觉建议：使用横向流程条，将“数据 -> 模型 -> 训练 -> 推理 -> 评估”放在同一页。

### 第 7 页：团队的实验规划思路

- 这一页只承担承上启下作用，不强调探索分支的具体结果。
- 团队先搭建简化的 2D U-Net，跑通数据读取、训练、推理与统一评估。
- 在简化模型上规划四个探索方向：
  1. 数据质量与掩码；
  2. 预训练编码器；
  3. 损失函数；
  4. 输入分辨率。
- 说明这些探索用于理解问题和筛选改进思路，最终把重点集中到公开 U-Net++。
- 页面建议：使用一条从左到右的路线图“简化 2D U-Net -> 四项探索 -> U-Net++ 改进”，不要放四个分支的详细指标表。

### 第 8 页：团队对公开 U-Net++ 的改进

本页是团队实验部分的重点，建议使用左右对照表。

| 设计项 | 原公开方案 | 团队改进 |
| --- | --- | --- |
| 输入尺寸 | 256×256 | **320×320** |
| 编码器 | EfficientNet-B0 + ImageNet 预训练 | 保持不变 |
| 数据增强 | 公开代码设置 | 保持不变 |
| 优化器与训练轮数 | AdamW、余弦退火、50 epochs | 保持不变 |
| 主损失 | Dice+BCE | 保留 Dice+BCE |
| 辅助损失 | 无 | **增加 Focal Tversky 辅助项** |
| 总损失 | Dice+BCE | `0.8 × (0.5 Dice + 0.5 BCE) + 0.2 × FocalTversky` |

强调相比原公开代码的优势：

- 320×320 比 256×256 保留更多空间细节，有利于观察较小病灶和边界。
- Focal Tversky 辅助项让训练更关注难分类像素和前景区域，与原有 Dice+BCE 形成互补。
- 保留预训练 EfficientNet-B0、数据增强、AdamW、余弦退火和 50 epochs，使改进建立在原公开代码的强基线上。
- 保留 Dice+BCE 作为主损失，在增强难样本学习的同时维持原有全局分割训练目标。
- 改动范围明确，便于与原公开方案进行对照，并保持训练流程稳定。

### 第 9 页：U-Net++ 改进的实现细节

- 输入统一调整为 320×320，图像与掩码同步裁剪和缩放，掩码使用最近邻插值避免标签被插值破坏。
- 保留 ImageNet 预训练 EfficientNet-B0 编码器。
- 使用 Dice+BCE 作为主损失，以 Focal Tversky 作为辅助损失。
- 训练使用混合精度、梯度裁剪、AdamW 和余弦退火，保持公开方案的训练框架。
- 在验证集上保存最佳权重，再在测试集上评估 Dice、IoU、Precision 和 Recall。
- 视觉建议：画一个分层流程，第一层是数据处理，第二层是 U-Net++，第三层是“主损失 + 辅助损失”和评估。

### 第 10 页：定量结果

建议将“原公开方案”和“团队改进方案”放在同一张表，突出团队改进效果。

| 指标 | 原公开 U-Net++ | 团队改进方案 |
| --- | ---: | ---: |
| 全部图像平均 Dice | 0.8354 | **0.8523** |
| IoU | 0.8154 | **0.8197** |
| 阳性病例 Dice | 未报告 | **0.8449** |
| Precision | 未报告 | 0.8974 |
| Recall | 未报告 | **0.8860** |

- 改进方案在全部图像平均 Dice 上相对原公开结果提高 **0.0169**，IoU 提高 **0.0043**。
- 阳性病例 Dice 达到 **0.8449**，说明改进不只体现在背景区域。
- 讲解重点：320×320 与辅助损失组合后，模型在细节表达和病灶召回方面表现更好。
- 如果最终答辩版使用了更新后的复核结果，必须用同一测试集重新生成整张表，不能混用不同版本的数字。

### 第 11 页：分割结果可视化

- 优先使用改进方案的 `test_predictions.png`、`viz_bleeding_grid.png` 和 `viz_ischemia_grid.png`。
- 每张图建议包含原始 CT、真实掩码、预测掩码和重叠图。
- 统一图例：红色表示真实掩码，绿色表示预测，黄色表示重叠，蓝色表示漏检或误报。
- 选择一张成功样例和一张困难样例，说明模型在病灶边界、病灶大小和不同类别上的表现。
- 图注中写清模型名称、测试集和病例编号，避免与团队前期探索结果混淆。

### 第 12 页：项目结论

- 主模型结论：公开 U-Net++ 使用预训练 EfficientNet-B0 编码器和嵌套多尺度融合，是本项目的核心方案。
- 团队改进结论：在保留公开代码训练框架的基础上，引入 320×320 输入和 Focal Tversky 辅助损失，使模型更关注细节、难样本和前景区域。
- 定量结论：改进方案全部图像平均 Dice 为 **0.8523**，高于原公开结果的 **0.8354**；阳性病例 Dice 为 **0.8449**。
- 方法优点：
  - 预训练特征表达强；
  - U-Net++ 的多尺度融合适合医学图像分割；
  - 改进保持与原公开方案的可比性；
  - 主损失与辅助损失结合，兼顾整体分割与难样本学习。
- 不足与改进方向：
  - 超小病灶和复杂边界仍然困难；
  - Bleeding 与 Ischemia 的表现存在差异；
  - 可以继续调整辅助损失权重、数据增强、后处理和模型集成。

## 三、讲解重点

### 1. 先讲公开 U-Net++，再讲团队改进

推荐讲稿：

> 本项目的核心模型是公开 U-Net++，它使用预训练的 EfficientNet-B0 编码器和嵌套跳跃路径融合多层特征，公开测试集报告 Dice 0.8354、IoU 0.8154。团队先搭建简化 2D U-Net，跑通完整流程，并从数据、编码器、损失和分辨率四个方向形成实验规划。最终把重点放到公开 U-Net++ 上：输入提升到 320×320 以保留更多细节，同时在原有 Dice+BCE 主损失之外加入 Focal Tversky 辅助项，让模型更关注难样本和前景区域。改进后的全部图像平均 Dice 达到 0.8523，阳性病例 Dice 达到 0.8449。

### 2. 团队实验部分的讲法

- 简化 2D U-Net 和四个探索方向只说明“为什么做、形成了什么规划思路”。
- 不逐项展示四个探索分支结果，不比较各分支的失败细节。
- PPT 页面不展示内部实验编号。
- 团队实验部分的中心结论是：探索用于形成改进思路，最终成果落在公开 U-Net++ 的 320×320 和辅助损失改进上。

### 3. 数字使用规则

- 公开 U-Net++ 数字来源：`docs/公开模型分析.md`。
- 团队改进结果来源：已合并到远端的公开 U-Net++ 改进实验报告与指标文件。
- 两张表的测试集必须一致，当前定量结果来自同一个 998 例测试集。
- 所有指标保留四位小数，并与结果文件保持一致。
- 如果答辩前更新训练结果，整张表统一替换，不混用新旧数字。

### 4. 建议控制在 10 至 12 分钟

- 背景与数据：1.5 分钟。
- U-Net++ 原理与实现：3.5 至 4 分钟。
- 团队实验规划与 U-Net++ 改进：2.5 至 3 分钟。
- 定量结果与可视化：2 分钟。
- 结论与团队分工：1.5 分钟。
