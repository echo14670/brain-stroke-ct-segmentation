# 公开模型分析

本文件用于满足课程要求的“理解所选题目已上传公开模型”。分析对象为该 Kaggle 数据集页面关联的公开 Notebook。

## 对比结论

当前 `baseline-v1` 是团队的最小控制组，不是追求高分的最终模型。公开高分 Notebook 使用了预训练编码器、更长训练和更强的数据处理。

| 方案 | 模型与训练 | 报告 Dice | 指标口径 | 主要问题 |
| --- | --- | ---: | --- | --- |
| 本团队 baseline-v1 | 从零训练 U-Net，8 epochs | 0.3016 | 阳性病例逐图平均 | Ischemia 几乎失败，训练后期塌缩 |
| 本团队同口径换算 | 同上 | 0.3574 | 全部内部测试图像平均 | 仍明显低于公开方案 |
| 公开 MANet | ImageNet ResNet50 + MANet，100 epochs | 0.8281 | 验证集 micro-imagewise | PNG/DICOM 重复入集，随机切分存在泄漏风险，未报告独立测试 Dice |
| 公开 U-Net++ | ImageNet EfficientNet-B0 + U-Net++，50 epochs | 0.8354 | 测试集全部图像平均 | 阳性病例逐图 Dice 未单独报告 |

## 公开方案来源

- [Brain stroke segmentation MANet 83% Dice score](https://www.kaggle.com/code/rashidrk/brain-stroke-segmentation-manet-83-dice-score)
- [Phân đoạn ảnh đột quỵ / U-Net++](https://www.kaggle.com/code/quanglam19082004/ph-n-o-n-nh-t-qu)

## 对公开方案的判断

### MANet 示例

- 使用 ImageNet 预训练 ResNet50 编码器。
- 使用 MANet、加权随机采样、数据增强和 Dice Loss。
- 训练 100 个 epoch，前 15 个 epoch 冻结编码器。
- 同一病例的 PNG 和 DICOM 被分别加入数据集，再进行随机切分。
- 日志中的数据集数量为 Train 6388、Validation 710、Test 1775，合计 8873，说明训练、验证和测试之间存在同一病例的重复视图。
- 因此其 0.8281 不能直接视为无泄漏的测试泛化结果。

### U-Net++ 示例

- 使用 ImageNet 预训练 EfficientNet-B0 编码器。
- 使用 U-Net++、Dice+BCE 混合损失、数据增强和学习率调度。
- 训练 50 个 epoch。
- 测试集为 998 张图像，报告 Dice 0.8354、IoU 0.8154。
- 该指标对 Normal 空掩码和空预测使用 epsilon，得到 Dice 约等于 1，因此全部图像平均会高于仅阳性病例平均。
- 公开 Notebook 未单独报告仅阳性病例的 Dice，不能直接与当前 0.3016 完全对齐。

## 对团队实验设计的启示

1. 预训练编码器是本数据集最明确的增益方向，因此 E2 使用 ResNet34，并保持其他变量不变。
2. 数据质量对 Ischemia 至关重要，因此 E1 独立比较基础红色掩码和红蓝并集掩码。
3. 公开方案普遍训练 50 至 100 个 epoch，而当前控制组只完成 8 个 epoch，因此当前成绩不能代表模型结构上限。
4. 所有团队实验必须使用同一固定切分和阳性病例平均 Dice，避免通过 Normal 空图抬高指标。
5. 最终组合最多采用两个验证集表现最好的方向，不以公开 Notebook 标题中的单一 Dice 数字替代本团队统一评估。
